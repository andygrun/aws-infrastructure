# AWS Infrastructure

A project-based repository for learning **AWS infrastructure deployment** using **Terraform** for **Infrastructure as Code (IaC)**.

## Goals

- Learn AWS infrastructure fundamentals
- Build infrastructure using Terraform
- Practice least-privilege IAM
- Deploy and manage AWS resources reproducibly
- Document infrastructure decisions and troubleshooting
- Practice monitoring and alerting

## Labs

### Lab 1 — VPC, EC2 & S3

- VPC and subnet architecture
- EC2 in a private subnet
- AWS Systems Manager for instance access
- S3
- Least-privilege IAM
- Terraform deployment and teardown

### Lab 2 — Monitoring & Alerting

- CloudWatch
- SNS
- EC2 alarms
- S3 alarms
- Threshold justification
